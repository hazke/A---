## 安装步骤

### 1. 设置虚拟环境（推荐方式）

**使用自动脚本（最简单）：**

**Windows:**
```bash
# 双击运行或命令行执行
setup_venv.bat
```

**Linux/Mac:**
```bash
chmod +x setup_venv.sh
./setup_venv.sh
```

脚本会自动：
- ✅ 创建Python虚拟环境（`venv`目录）
- ✅ 激活虚拟环境
- ✅ 升级pip
- ✅ 安装所有依赖（核心模块 + 后端API）

**手动设置虚拟环境：**
```bash
# 进入项目根目录
cd D:\CursorWorkspace\a-stock-quant

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate

# 安装所有依赖（使用合并的依赖文件）
pip install -r requirements-all.txt
```

**不使用虚拟环境（不推荐）：**
```bash
# 安装核心模块依赖
pip install -r requirements.txt

# 安装后端API依赖
pip install -r backend/requirements.txt
```

### 2. 安装Node.js依赖（前端）

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install
# 或使用yarn
yarn install
```

## 配置说明

### 数据源配置

编辑 `config/config.yaml` 文件：

```yaml
data_source:
  default: akshare  # 推荐使用akshare（无需token）
  # 或使用tushare（需要token）
  tushare:
    token: "你的tushare_token"  # 从 https://tushare.pro/ 获取
```

**数据源选择：**
- **akshare**：免费，无需token，推荐新手使用
- **tushare**：需要注册获取token，数据更稳定

## 常见问题

### 1. Python模块导入错误

**问题：** `ModuleNotFoundError: No module named 'xxx'`

**解决：**
```bash
# 确保安装了所有依赖
pip install -r requirements.txt
pip install -r backend/requirements.txt
```

### 2. 端口被占用

**问题：** `Address already in use`

**解决：**
- 后端端口8000被占用：修改 `backend/main.py` 中的端口号
- 前端端口5173被占用：Vite会自动使用下一个可用端口

### 3. 数据获取失败

**问题：** 无法获取股票数据

**解决：**
- 检查网络连接
- 如果使用tushare，检查token是否正确
- 尝试切换到akshare（无需token）

### 4. 前端无法连接后端

**问题：** 前端报错 `Network Error`

**解决：**
- 确保后端已启动（http://localhost:8000）
- 检查 `frontend/vite.config.ts` 中的代理配置
- 检查浏览器控制台的错误信息

### 5. CORS错误

**问题：** 浏览器控制台显示CORS错误

**解决：**
- 检查 `backend/main.py` 中的CORS配置
- 确保前端地址在允许列表中

### 6. 前端构建错误

**问题：** `npm install` 失败

**解决：**
```bash
# 清除缓存
npm cache clean --force

# 删除node_modules重新安装
rm -rf node_modules
npm install
```

## 开发模式 vs 生产模式

### 开发模式（当前配置）

- **后端**：自动重载（`--reload`），便于开发
- **前端**：热模块替换（HMR），实时更新

### 生产模式

**后端：**
```bash
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --workers 4
```

**前端：**
```bash
cd frontend
npm run build
# 部署 dist 目录到Nginx等Web服务器
```
